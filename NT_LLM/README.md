# Local data and live helper modules

Start with the repository [README](../README.md) or [aggregate review snapshot](../review/README.md). This directory also preserves protected local source data, reference workbooks, frozen runs, tokenizer caches, and restricted exports at their original paths.

Only this README and four live helper modules are included by default in Git: `validation.py`, `label_schemes.py`, `narcolepsy_analysis.py`, and `narcolepsy_report.py`. Other contents are ignored local material; see [data and access](../docs/DATA_AND_ACCESS.md). Historical A and later raw runs remain available locally and indexed by the [experiment registry](../docs/EXPERIMENTS.md).

`final_packet_20261117/general` is a compatibility link to the canonical `review/` directory. Its restricted appendix remains local; it is not part of the aggregate deliverable. Historical dataset and Word files are preserved but are not current methods documentation.
