# Frozen inference snapshots

The two directories preserve the original B and combined parent runs' executed code and configurations. They are version evidence, not the current code entry points or an instruction to restart inference. Live modules remain at their original repository paths.

Historical A's recorded manifest and prompt are retained one level above; an exact frozen historical environment/model digest was not established and has not been fabricated. See the [experiment registry](../../../docs/EXPERIMENTS.md) and [provenance guide](../README.md).
